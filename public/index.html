Claude Session Tracker

Select a session to see its content.

How this works

Statuses

📝 To Do
Not started or not touched recently; nothing suggests it's active.
🔄 In Progress
Auto-set whenever the CLI reports the session as live/running. Reverts automatically when it stops running, unless you've manually overridden the status (dragging or picking one yourself marks it "manually set" and the tracker stops auto-managing it).
🚫 Blocked
Manual only — set this yourself when you're stuck on something and want it to stand out from ordinary To Do work.
✅ Done
Manual only — never auto-suggested. Set it yourself once work is actually finished.
🗄️ Archived
Manual only, never auto-suggested. Archiving never touches the underlying transcript file — it's purely a status flag here.

Badges

Needs You
The last thing that happened in the transcript was the assistant using a tool with no reply after it — usually a pending permission prompt. Doesn't detect a plain question in the text, only this specific "waiting on you" signal.
Stale
Was In Progress but hasn't been touched past the stale threshold, and running has stopped — flagged only, status stays In Progress. Only In Progress sessions get this; an untouched To Do/Blocked just stays as-is with no auto-flip.
Pinned
Purely a sort flag, set by you (checkbox in a session's detail pane). A pinned session always sorts to the top of its project group, above Needs You/Stale/manual order. No other effect.
● live dot
The CLI currently reports this session as running.

Actions

Resume
Reopens this exact session by its ID. Disabled (shows "Already open") if it's already running — you can't resume a session that's live elsewhere.
Fork
Same as Resume, but starts a brand-new session from this one's history instead of continuing it — the original session is left completely untouched. Use it to try a different direction without risking what you already have.
Continue latest in project
Not tied to the session you're viewing — runs Claude Code's own "continue most recent" for that project folder, so it can land on a different, newer session than the one you clicked. If a session in that project is already running, this skips launching anything and tries to focus its window instead (falls back to just selecting it here if the OS blocks the focus switch).
Copy command
Puts the equivalent CLI command on your clipboard, in case a spawn button misbehaves.
+ New Session
Pick a known project or browse to a folder, then launches a fresh `claude` there. It won't show up in this list until you send it a first message — Claude Code doesn't create a session record for a still-blank prompt.

Other

Filters
"All" means all active work (To Do / In Progress / Blocked) — Done and Archived are deliberately excluded from it and only show via their own chips.
Reordering
Drag a session card onto another card in the same project to set a manual order — it's a tiebreaker only; Needs You/Stale/Pinned still always float to the top. Project groups themselves reorder via the ↑↓ buttons on their header.
Window focus
All launches open as a new tab in your existing terminal window rather than a separate window, when possible. Bringing a window to the foreground from here is best-effort — Windows restricts background apps from stealing focus, so it can occasionally just select the session here instead of visibly focusing it.
